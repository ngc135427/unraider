# 可选 Unraid 相册助手

## Goal

提供可选的 Unraid 轻量助手，加速历史远端图库索引、缩略图/视频封面生成和完整性作业，同时保证移除助手后原件与纯客户端核心仍可用。

## Dependencies

- 阻塞依赖：`photo-backup-foundation` 的远端资产契约和 `photo-preview-gallery` 的派生媒体键/布局契约。
- 不得成为 `photo-transfer-engine` 或 `photo-background-operations` 的运行依赖。
- 后续 `photo-intelligence` 与 `photo-video-transcoding` 可扩展本任务的版本化作业 API。

## Requirements

- 提供版本化、可鉴权、可发现且按能力协商的 API；客户端能区分未安装、离线、未授权和版本不兼容。
- 扫描用户配置的媒体根目录，排除 `.unraider/`，输出可分页且带版本键的资产索引。
- 支持幂等、可重试、可查询进度的缩略图、视频封面和哈希/完整性作业。
- 派生数据写入明确的 `.unraider/` 布局，全部可删除和重建。
- 助手不得拥有定位或恢复原件所需信息的唯一副本，也不得改变原始目录语义。
- 助手不可用时客户端明确降级，并继续完成原件备份、浏览和新媒体 sidecar 工作。

## Acceptance Criteria

- [x] 客户端能协商助手版本和能力，并对不可用状态给出明确原因与重试入口。
- [x] 历史目录可增量索引并批量生成图片缩略图与视频封面，不需把原件传回手机处理。
- [x] 重复提交同一作业不会产生冲突派生文件或重复资产。
- [x] 停止或卸载助手后，原件、基础文件夹/时间线浏览及纯客户端备份仍可使用。
- [x] 删除派生目录后可通过作业完整重建，不影响任何原始文件。

## Notes

- 本任务属于可选增强，可在核心预览契约稳定后实施。
