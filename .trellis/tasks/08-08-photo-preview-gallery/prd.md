# 远端图库预览与大图库浏览

## Goal

让远端照片和视频像成熟 NAS 相册一样快速可见：网格只加载派生预览，大图库可分页浏览，并同时提供时间线、文件夹和媒体类型视图。

## Dependencies

- 阻塞依赖：`photo-backup-foundation` 的 `RemoteAsset`、版本键和分页查询契约。
- 集成依赖：`photo-transfer-engine` 提供新媒体 sidecar 的可靠上传能力；本任务可先实现本地生成和缓存部分。
- `photo-management-basics` 依赖本任务的统一资产仓库和选择模型。

## Requirements

- 网格不得下载完整原图；图片使用网格缩略图，视频使用封面帧并显示时长。
- 新上传媒体在本机生成 sidecar；历史远端媒体按“远端 sidecar、磁盘缓存、限流按需生成”顺序解析。
- 缓存落盘，按字节预算和 LRU 淘汰，并通过目标、路径和 size/mtime/ETag 版本键失效。
- 图库仓库提供稳定分页/游标，支持时间线、文件夹、照片和视频视图；逻辑相册只引用资产 ID。
- 详情页按需加载高清图；视频使用 Range 或兼容播放路径，网格预览与详情缓存相互独立。
- 助手缺失时仍能浏览原件和新上传 sidecar；助手可用时允许批量补齐历史派生媒体。

## Acceptance Criteria

- [x] 大于 8 MiB 的图片仍有网格缩略图，视频显示封面和时长。
- [x] 网格请求不读取完整原图，离开可见区域的预取可取消。
- [x] 应用重启后缩略图可命中磁盘缓存，远端版本变化后旧缓存自动失效。
- [x] 50,000 条索引资产下时间线和文件夹视图可分页滚动，内存不会随图库总量线性增长。
- [x] 未安装助手时基础图库可用；助手故障只显示降级状态，不阻断原件访问。
