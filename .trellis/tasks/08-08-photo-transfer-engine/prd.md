# 高吞吐安全传输引擎

## Goal

基于持久队列实现安全且可测量的媒体上传：显著提升大批量备份速度，同时保证中断、重试和渠道能力差异不会损坏远端原件。

## Dependencies

- 阻塞依赖：`photo-backup-foundation` 的媒体、目标、队列和状态迁移契约必须先完成。
- `photo-preview-gallery` 的新媒体 sidecar 上传和 `photo-background-operations` 的后台执行依赖本任务。

## Requirements

- SMB 与 WebDAV 是 MVP 一级读写渠道；SFTP 保留为已有配置兼容兜底。
- 本地 `content://` 到远端必须使用原生或等价粗粒度流式传输，避免 1 MiB 分块跨 Dart/Kotlin 往返。
- 各目标复用会话并采用受控并发；初始默认并发 2，允许根据能力和测量调整。
- 统一执行排队、`.part` 写入、完成校验、安全提交和最终状态落库；单文件失败不得阻塞队列。
- 传输适配器显式声明 atomic move、Range、ETag、mtime、空间查询和断点续传等能力，并安全降级。
- 支持暂停、继续、取消、指数退避及可操作的错误分类；正常成功路径不得触发全量远端重扫。

## Acceptance Criteria

- [ ] SMB 和 WebDAV 均能完成流式上传、临时路径写入、大小校验及安全提交。
- [ ] SFTP 旧配置仍能按同一安全状态机完成备份。
- [ ] 同一目标可受控并发，单个损坏或不可读文件不影响其他任务继续。
- [ ] 网络中断或进程终止后不会产生被标记成功的截断文件，任务可安全重试或续传。
- [ ] 日常完成确认不执行全量远端目录扫描。
- [ ] 指标可分别报告本地读取、连接、建目录、上传、校验和提交耗时及吞吐。

## Notes

- 本任务属于核心 MVP，其他云盘/对象存储协议不在范围内。
