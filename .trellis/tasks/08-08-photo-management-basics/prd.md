# 基础相册管理

## Goal

在备份和浏览稳定后补齐常用照片管理能力，使用户无需牺牲普通文件目录即可组织、查找和安全清理手机媒体。

## Dependencies

- 阻塞依赖：`photo-backup-foundation` 和 `photo-preview-gallery`。
- “释放手机空间”额外依赖 `photo-background-operations` 提供远端已验证状态。
- 后续 `photo-intelligence` 与 `photo-sharing` 依赖本任务的逻辑相册和元数据模型。

## Requirements

- 逻辑相册只保存资产引用，不复制或移动原始文件；可选映射手机相册。
- 支持收藏、归档、标签、描述和评分等可重建或可导出的元数据。
- 基础搜索与筛选覆盖文件名、目录、日期、媒体类型和基础 EXIF。
- 精确重复项提供分组与人工复核，不自动删除；默认只依据可靠哈希或等价强身份判断。
- “释放手机空间”只选择远端原件已验证的本地媒体，先显示清单和预计释放容量，再调用系统允许的删除流程。
- 支持受预算控制的近期媒体离线缓存，不将缓存误认为唯一副本。

## Acceptance Criteria

- [ ] 时间线、文件夹和逻辑相册引用同一资产，创建/删除逻辑相册不复制或删除原件。
- [ ] 用户可按文件名、目录、日期和媒体类型搜索/筛选。
- [ ] 重复项页面只列出强匹配候选，并要求用户确认删除对象。
- [ ] 释放空间预览排除未验证、失败或仅本地媒体，并显示项目数与容量。
- [ ] 删除被系统拒绝或部分失败时，状态准确回写且不影响远端备份记录。

## Notes

- 本任务属于核心 MVP 的最后阶段；不包含 AI、地图或多人共享。
