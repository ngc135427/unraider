# 视频兼容转码

## Goal

为无法被客户端直接播放的远端视频提供可选助手端兼容转码和播放能力协商，同时保留原始视频并限制资源占用。

## Dependencies

- 后续任务；不属于核心 MVP。
- 阻塞依赖：`photo-nas-helper` 的版本化作业 API 和 `photo-preview-gallery` 的播放/缓存契约。

## Requirements

- 播放前先协商客户端、容器、视频/音频编码和 Range 能力，能直放时不得转码。
- 转码输出是可重建派生文件，不覆盖或替换原始视频。
- 作业支持排队、暂停、取消、进度、失败重试以及 CPU/GPU/并发/磁盘预算。
- 输出与原件版本绑定，原件变化后旧转码自动失效。
- 客户端在转码不可用时显示可理解的兼容性原因，并允许下载/调用外部播放器等安全降级。

## Acceptance Criteria

- [ ] 支持的视频走直接播放，不创建多余转码。
- [ ] 不兼容视频可生成可播放派生版本，原始文件保持字节不变。
- [ ] 助手重启后转码作业可恢复，重复请求不会重复占用空间。
- [ ] 达到资源预算时作业排队而不是拖垮备份、索引或缩略图任务。

## Notes

- 编码格式、硬件加速和输出档位在本子任务进入规划时单独确认。
